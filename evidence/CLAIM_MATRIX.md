## Deliberate omissions

The matrix does not publish source paths, implementation code, private signing material, proof-generation internals, model artifacts, internal databases, or infrastructure configuration.

## Interpretation

The public repository allows verification of what NightFall is claiming and how an external evaluator should challenge those claims. It does not independently reproduce the proprietary mechanism that generated the internal evidence.
