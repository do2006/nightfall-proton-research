# NightFall Proton Technical Report 1.0

## Abstract

Proton integrates durable cognitive state with NightFall Mimetic Cognitive Fabric (MCF) and its CSC learning path. The design separates live model weights from durable goals, memory, learned routes, bounded capabilities, evidence, health state, and recovery information.

## Learning lifecycle

Observed experience → recurrence qualification → bounded counterfactual analysis → candidate capability → independent proof classes → owner/company authorization → transactional promotion → bounded activation → monitoring → quarantine/rollback on invalidation.

## Verification properties

Published evidence addresses recurrence qualification, historical/replay/adversarial/canary proof classes, bounded resource and task applicability, transactional promotion, rollback points, drift failure-closed behavior, quarantine, and cross-platform execution.

## Phase 17 baseline

The sealed research-alpha evidence records 120 scenarios passed per platform, 36 failure-injection cases passed per platform, 10,000 property executions per platform, 10,000 native WSL2 libFuzzer runs, zero sanitizer findings, and valid eight-hour Windows and WSL2 certification soaks. The certification scope was local owner-controlled research, not public deployment.

## Proton promotion evidence

A later Proton agency capability record identifies proton-agency-v1, three recurring observations, bounded agency applicability, explicit excluded task classes, resource ceilings, replay/historical/adversarial/canary proof references, rollback requirements, quarantine behavior, company authenticity, an owner-authorized promotion transaction, and a trusted post-promotion hash.

## Disclosure boundary

This report describes externally testable properties. It intentionally omits proprietary implementation details sufficient to reconstruct MCF/CSC/Proton internals.
