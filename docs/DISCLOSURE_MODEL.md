# Disclosure Model

NightFall Proton uses a public-proof/private-implementation release model.

## Public

Externally testable claims, bounded architecture descriptions, benchmark specifications, sanitized results, evidence identifiers/hashes, demonstration protocols, limitations, and reproduction instructions.

## Private

Production Proton/MCF/CSC source, crystal-generation and qualification internals, proprietary orchestration and algorithms, model artifacts/weights, private databases, credentials, signing secrets, infrastructure details, and unrelated NightFall intellectual property.

The objective is falsifiability of published claims without providing a reconstruction recipe for the proprietary system.
