# NightFall Proton — Public Research Release 1.0

NightFall Proton is an experimental cognitive runtime integration from NightFall Technologies. This repository publishes verification material and reproducible evaluation interfaces without publishing the proprietary Proton, MCF, CSC, or NightFall production implementation.

## What this release demonstrates

The evidence package covers bounded learned-capability promotion, recurring-experience qualification, counterfactual candidate generation, proof-gated promotion, rollback, drift quarantine, cross-platform validation, and company-authenticated governance records.

## Evidence boundary

This is an evidence release, not an open-source release of Proton. Public artifacts are deliberately limited to claims, test methodology, non-secret hashes, sanitized results, and black-box evaluation specifications. Production source, model artifacts, internal orchestration, private keys, databases, credentials, and proprietary algorithms are excluded.

## Historical scope

Phase 17 CSC Research Alpha was certified as an owner-controlled local research pilot in August 2026 and explicitly did not authorize publication at that time. Later Proton integration/promotion evidence was produced in September 2026. This release preserves that chronology rather than retroactively changing the scope of the earlier certification.
