# Contributing and Independent Evaluation

This repository is an evidence and evaluation surface for proprietary NightFall Proton research, not an open-source implementation repository.

## Useful contributions

We welcome issues and pull requests that improve the public evaluation layer: reproducibility problems, ambiguous claims, evaluator fixtures, additional black-box tests, documentation corrections, integrity-check improvements, and independently produced results.

## Independent results

External evaluations should report the evaluator/environment, runtime and evaluator versions, fixture hashes, pass/fail criteria, deviations from the published specification, failures and ambiguities, and enough information for another evaluator to repeat the test.

Negative results are useful. Please do not soften failures to match NightFall's published results.

## Out of scope

Do not submit credentials, private keys, model weights, proprietary Proton/MCF/CSC source, internal infrastructure details, or reverse-engineered confidential material.

For security-sensitive findings, follow SECURITY.md instead of opening a public issue.
