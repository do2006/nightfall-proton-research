# NightFall Technologies Publishes Proton Public Research Release 1.0

**Evant, Texas — September 28, 2026** — NightFall Technologies has published the first public research/evidence release for NightFall Proton, a working integration of durable cognitive state with the company's Mimetic Cognitive Fabric (MCF) and Counterfactual Skill Crystallization (CSC) research.

Rather than publishing the proprietary Proton implementation, the release exposes bounded claims, machine-readable evidence summaries, integrity hashes, black-box evaluation specifications, and a public demonstration protocol. The goal is to make the research externally challengeable without providing a reconstruction recipe for the underlying technology.

The published evidence covers recurring-experience qualification, bounded candidate capabilities, counterfactual analysis, replay/historical/adversarial/canary proof classes, authorized transactional promotion, drift quarantine, and rollback/recovery controls.

The accompanying Phase 17 research-alpha evidence records 120 scenarios passed per platform, 36 failure-injection cases per platform, 10,000 property executions per platform, 10,000 native WSL2 libFuzzer runs, and zero sanitizer findings. NightFall identifies these as internally produced research results rather than independent third-party certification.

The public repository includes verification scripts, a claim-to-evidence matrix, technical documentation, a disclosure model, and a stable v1.0.0 release. Production Proton/MCF/CSC source, proprietary algorithms, model artifacts, credentials, signing secrets, and internal databases remain private.
