# Research / Partner Outreach

Subject: NightFall Proton — public evidence release for governed persistent cognition

NightFall Technologies has published Proton Public Research Release 1.0, a public evidence package for our work on persistent governed cognition.

The release focuses on an experience-to-capability lifecycle in which recurring observations can produce bounded candidates, but trusted activation remains evidence- and authorization-gated, with rollback and quarantine controls retained after promotion.

We deliberately kept the production Proton/MCF/CSC implementation private. The public package instead provides a technical report, machine-readable claims, black-box evaluation specification, integrity hashes, a claim-to-evidence matrix, and a demonstration protocol.
